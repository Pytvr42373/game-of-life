# 黎明迷局 · MIDNIGHT PURSUIT

2D「第五人格」风格 **不对称追逃游戏** —— 纯前端、零外部依赖、全程序化绘制、可离线运行。

- 单机可玩：1 名求生者（玩家）+ 2 名 AI 队友 vs AI 监管者；或扮演监管者 vs 3 名 AI 求生者。
- 暗黑哥特 / 维多利亚悬疑风：深色、迷雾、烛火、冷蓝月光 + 暖暗光，程序化角色与音效（WebAudio）。
- 本地存档（localStorage）：设置、最高分、胜场。

## 运行方式
直接打开 `index.html`（无需服务器，离线可玩）。桌面端建议浏览器全屏；移动端自动出现虚拟摇杆与按钮。

## 文件结构
| 文件 | 说明 |
|------|------|
| `index.html` | 页面壳：画布、哥特风菜单/HUD DOM、触摸控件 |
| `maps.js` | 3 张地图数据 + 网格解析 + 连通性校验（雾夜教堂/荒芜庄园/废弃医院） |
| `chars.js` | 6 求生者 + 2 监管者：数值/技能/背景/绘制样式 |
| `game.js` | 核心引擎：碰撞/寻路/修机校准/战斗/处刑/逃生/胜负，纯逻辑可在 node 驱动 |
| `ai.js` | 监管者与求生者 AI 状态机 |
| `audio.js` | WebAudio 程序化音效：心跳/修机/校准/攻击/传送/氛围低鸣/追逐压迫 |
| `ui.js` | 程序化渲染、HUD、菜单、输入（键盘+触屏） |
| `test.js` | node 关键逻辑自测（40 项） |
| `smoke.js` | DOM/canvas stub 运行时冒烟测试 |
| `dawn-map-*.png` | 三张地图布局预览图 |

## 操作
- 移动 `WASD / 方向键`（触屏：左下摇杆）
- 交互 `E / 空格 / 回车`（触屏：右下按钮）—— 修机/放板/救援/治疗/开门/翻窗自动；倒地时 `空格` 为自愈
- 技能 `Shift`；监管者技能2 `Q`；蹲伏 `C / Ctrl`；暂停 `P / Esc`
- 监管者：空格=攻击（命中后擦刀 1s），E=抱起/挂椅/放下/耗时拆板

## 核心规则
- 求生者：破译 3 台密码机 → 大门通电 → 开门并走出 → 逃脱即胜；破译必须停留在机器旁，离开立即停止。
- 监管者：命中 2 次倒地 → 牵制 → 挂处刑架，倒计时结束淘汰；淘汰全部求生者即胜。
- 校准：修机时指针入绿区按交互 = 完美(+4%)，失败扣进度并暴露位置（破译专家不受损）。
- 窗户双方均可翻越，监管者耗时更长；板子按 E 放下可砸晕监管者，放下后求生者可翻越，监管者按 E 耗 1.8s 摧毁（期间不能行动）；板子一次性。
- 受伤移速不变，受击获得 2s 30% 加速；仅倒地可按空格自愈，受伤需队友治疗；处刑架可救援、可挣扎挣脱。

## 难度
休闲 / 普通 / 噩梦：影响监管者移速、视野、攻击间隔、追击放弃时间、守尸时间与挣脱难度。

---
技术备注：游戏逻辑（game.js / ai.js / maps.js）不依赖 DOM，可直接在 node 中驱动；
运行 `node test.js` 执行 40 项逻辑自测，`node smoke.js` 执行运行时冒烟。
