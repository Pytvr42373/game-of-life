# 深潜打捞 · DEEP SALVAGE

好玩游戏频道中的单机水下搜打撤游戏。玩家与两名自主 AI 潜水员进入沉船海沟，在氧气耗尽前搜刮宝物和永久装备，并躲避具有栖息范围与动态追踪逻辑的鲨鱼。

## 核心规则
- 玩家探灯只照亮面向方向；面向随移动方向变化。
- 氧气持续消耗，冲刺改用独立耐力。氧气归零后 3 秒失败，地图内可搜到氧气。
- 全图有两处贴近岩壁的鲨鱼巢穴。鲨鱼会动态感知、追踪并把目标拖回巢穴；首次可被队友救出并进入流血状态，第二次被拖回直接淘汰。
- 护卫和打捞员会在救援、搜索、补氧与躲避之间自主决策，转向带速度限制，探照灯不会瞬间左右闪烁。
- 旋涡按距离中心的远近减速；缠绕海草生长在岩壁边缘，触发一次后消失并束缚 2 秒；固定水雷触发后减速 2 秒。
- 背包有 6 格。带至少一件宝物返回母船并按 `E` 即可撤离。
- 成功撤离后，找到的普通至传奇装备进入局外仓库并在后续潜航中生效。

## 永久装备
| 装备 | 品质 | 效果 |
|---|---|---|
| 增压阀 | 普通 | 最大氧气 +20 |
| 声呐模块 | 精良 | 周期显示附近物资 |
| 抓钩 | 稀有 | 海草束缚缩短至 1 秒 |
| 探照灯 | 史诗 | 探灯距离 +80px |
| 推进器 | 传奇 | 移速 +15%，降低冲刺耐力消耗 |

## 操作
- `WASD` / 方向键：游动并改变面向
- `Shift` / `Space`：消耗耐力冲刺
- `E`：在母船附近撤离
- `P` / `Esc`：暂停
- 移动端提供方向与动作按钮
