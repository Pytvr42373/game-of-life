命名空间是 C++ 解决"名字冲突"的机制——相当于给函数贴上"姓氏"。
💡 命名空间核心知识
什么是命名空间？
命名空间（namespace）是给名字加"姓氏"的机制。
std::cout 表示"std 这个家族里的 cout"。
就像学校里有两个"张伟"，用"三年级的张伟"和"五年级的张伟"来区分。
using namespace std; 的含义
using namespace std; 相当于说"这一页用到 std 家族的人就不用加姓氏了"。
写了它：直接用 cout
不写它：必须写 std::cout
竞赛中几乎都写，省时间少打字。
为什么需要命名空间？
C++ 标准库有几千个名字（cout、cin、sort、vector、max、min...）。
如果你的代码里也有个 max 函数，编译器不知道用哪个。
有了命名空间：std::max 是标准库的，::max 是你的，不会命名冲突。
Python 对比
Python 的 import math 要求写 math.sqrt()，相当于"带姓氏"。
Python 的 from math import * 可以直接写 sqrt()，相当于 using namespace。
C++ 的 using namespace std; 就是 from std import * 的意思。
📌 竞赛小贴士
竞赛代码中 using namespace std; 是标配，GESP 考试也建议写。
但在大型工程中不推荐，因为容易引发命名冲突。竞赛追求速度，工程追求安全。
