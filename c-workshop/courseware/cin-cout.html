cin 和 cout 是 C++ 标准输入输出流。>> 是"提取"（读入），<< 是"插入"（输出）。
💡 cin / cout 核心知识
<< 和 >> 的方向
数据流动方向就是箭头方向：
cout << x — 数据流向 cout（输出到屏幕）
cin >> x — 数据从 cin 流入 x（从键盘读入）

口诀：箭头指向谁，数据就流向谁。
cin 的自动分隔
cin >> a >> b 输入 10 20 时，cin 遇到空格/换行自动分隔。
连续读多个：输入 1 2 3，cin >> a >> b >> c 分别得到 1、2、3。
要读整行（含空格）用 getline(cin, str)。
endl vs \n
endl — 换行 并刷新缓冲区（把数据立刻推到屏幕）
\n — 只换行，不刷新缓冲区

竞赛中 \n 更快，因为不频繁刷新。endl 更安全但更慢。
速度优化
cin/cout 默认与 scanf/printf 同步，速度较慢。
竞赛中常用：
ios::sync_with_stdio(false);
cin.tie(0);
关闭同步后速度接近 scanf/printf，但不能混用 cin 和 scanf。
📌 竞赛小贴士
大数据量（百万级读入）时，cin/cout 不加优化可能 TLE（超时）。
两种方案：① 加 ios::sync_with_stdio(false); cin.tie(0);，② 直接用 scanf/printf。
GESP 初级题数据量小，cin/cout 完全够用。
